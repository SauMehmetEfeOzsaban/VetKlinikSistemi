 Proje Hakkında
Bu proje, ASP.NET Core MVC .NET 10  kullanılarak geliştirilen bir Veteriner Kliniği Randevu ve Hasta Takip Sistemidir. 
Sistem klinik ve hizmet tanımlamaları, veteriner hekim ve müsaitlik yönetimi, evcil hayvan ve aşı takibi, çakışma kontrollü randevu mekanizması,
LINQ tabanlı REST API ve yapay zekâ asistanlarının erişebileceği bir MCP sunucusunu içermektedir.

Kullanılan Teknolojiler
- ASP.NET Core MVC .NET 10, C#
- Entity Framework Core, LINQ
- SQL Server
- ASP.NET Core Identity
- ModelContextProtocol.AspNetCore (MCP C# SDK)
- Bootstrap 5, HTML5, CSS3, JavaScript, jQuery
